      Set up a computer
      
          
      Run one command in a terminal on each computer you work on. It installs the backchannel command, signs the computer in as you, and connects Claude Code and Codex if they're installed. Needs Node.js 22.13 or newer.
      
          
          
      
          
      The command contains a one-time sign-in link: it works once, within 10 minutes, and no token is copied around.
      
          
      Then restart open Claude Code and Codex sessions; they connect when they start. Something not working? Run backchannel doctor.
